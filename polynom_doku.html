1Überblick#

polynom.py ist das Gegenstück zu vektor.py für die Analysis: ein Python-Modul für ganzrationale Funktionen (Polynome). Es rechnet exakt mit Brüchen und Wurzeln, erzählt auf Wunsch den Lösungsweg – als Text oder als LaTeX –, zeichnet Graphen mit allen besonderen Punkten und öffnet dieselbe Aufgabe auf der passenden Übungsseite der Mathe-Tools.

Das Modul ist eine einzelne Datei und braucht nur Python 3. Für Bilder wird matplotlib benutzt, wenn es installiert ist – sonst gibt es eine Skizze aus Zeichen.

from polynom import *f = Polynom("f(x) = -x^4 + 5x^3 + 6")f.extrempunkte()[H(15/4 | 18411/256) ≈ H(3,75 | 71,92)]f.nullstellen()[-1, ≈5,05]

Drei Dinge unterscheiden das Modul von einem Taschenrechner:

  • Exakt. H(15/4 | 18411/256) statt 3,75 und 71,918…; Wurzeln bleiben Wurzeln (2√3/3). Wo es exakt nicht geht, steht ehrlich ein ≈.
  • Mit Lösungsweg. Jede Rechnung kann ihren Weg in Schulschreibweise erzählen – auch als LaTeX. .link() öffnet dieselbe Aufgabe auf der Übungsseite.
  • Bequeme Eingabe. x^2, x², x^(2) (GeoGebra), 2(x-1)(x+3)^2, 1/3 x^3, 0,5x – oder über die Nullstellen.

Modul laden#

Am einfachsten liegt polynom.py im selben Ordner wie das eigene Skript oder Notebook (wie vektor.py):

from polynom import *          # alles auf einmal (empfohlen)

import polynom                # oder mit Vorsatz
f = polynom.Polynom("x^2 - 4")
Tipp hilfe() druckt eine Kurzanleitung, dir(f.weg) zeigt alle Rechnungen mit Lösungsweg, und jede Methode hat einen Docstring: help(Polynom.tangente).

3Die drei Konventionen#

Wie bei vektor.py folgt alles denselben drei Regeln.

1. Methoden liefern das Ergebnis – nie Text#

Jeder Aufruf gibt das mathematische Objekt zurück: eine Zahl, ein Polynom, eine Liste von Punkten oder Intervallen. Damit kann sofort weitergerechnet werden.

t = f.tangente(2)tt(x) = 28x - 26t.nullstellen()[13/14]H = f.extrempunkte()[0]H.x, H.y(15/4, 18411/256)

2. Derselbe Aufruf über .weg liefert den Lösungsweg#

f.weg.methode(...) rechnet dasselbe, gibt aber eine Rechnung zurück: print zeigt den Weg, .tex() liefert LaTeX, .ergebnis das Ergebnis, .link() die Aufgabenseite.

r = f.weg.tangente(2)r.ergebnist(x) = 28x - 26print(r)Tangente an f bei x = 2-----------------------Berührpunkt: y-Koordinate  f(2) = -2⁴ + 5·2³ + 6 = -16 + 40 + 6 = 30Steigung der Tangente: m = f'(2)  f'(x) = -4x³ + 15x²  f'(2) = -4·2³ + 15·2² = -32 + 60 = 28Ansatz t(x) = m·x + b – Punkt einsetzen und nach b auflösen:  30 = 28·2 + b  b = -26Tangentengleichung:  t(x) = 28x - 26

3. Gerechnet wird exakt#

Koeffizienten sind Brüche, Lösungen quadratischer Gleichungen sind Wurzelzahlen (a + b·√r). Nur wo es exakt nicht geht – etwa bei der Nullstelle von x³ − 6x² + 6x − 6 – entsteht eine Naeherung; sie wird immer mit ≈ angezeigt.

g = Polynom("x^3 - 4x")g.extrempunkte()[H(-2√3/3 | 16√3/9) ≈ H(-1,15 | 3,08), T(2√3/3 | -16√3/9) ≈ T(1,15 | -3,08)]g(Wurzelzahl(0, 2, 3) / 3)-16√3/9Polynom("x^3 - 6x^2 + 6x - 6").nullstellen()[≈5,05]
