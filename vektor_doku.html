1Überblick#

vektor.py ist ein Python-Modul für die analytische Geometrie der Oberstufe: Punkte, Vektoren, Geraden und Ebenen. Es rechnet exakt mit Brüchen und Wurzeln, liefert auf Wunsch den fertig formatierten Lösungsweg – als Text oder als LaTeX – und zeichnet alles in der eigenen Visualisierungsseite.

Das Modul ist eine einzelne Datei ohne Fremdbibliotheken. Es braucht nur Python 3. Bilder zeigt es auf der Visualisierungsseite der Mathe-Tools im Netz (analytische_geometrie.html auf lehrerkoch.github.io) – auf Wunsch auch mit einer Datei auf dem eigenen Rechner.

from vektor import *A = Punkt(1, 2, 3)E = Ebene("E: 2x + 3y + 4z = 12")A.abstand(E)8√29/29

Drei Dinge unterscheiden das Modul von einem Taschenrechner:

  • Exakt. 8√29/29 statt 1.4855627054164149. Gerundet wird erst, wenn eine Ausgabe es verlangt.
  • Mit Lösungsweg. Jede Rechnung kann ihren eigenen Weg erzählen – in Schulschreibweise, auch als LaTeX zum Einfügen in Arbeitsblätter. Und .link() öffnet dieselbe Aufgabe auf der passenden Übungsseite der Mathe-Tools – mit Quiz und Skizze.
  • Mit Bild. zeige(...) öffnet die Objekte in analytische_geometrie.html, mit Namen, Farben und allem.

Modul laden#

Am einfachsten liegt vektor.py im selben Ordner wie das eigene Skript oder Notebook:

from vektor import *          # alles auf einmal (empfohlen)

import vektor                 # oder mit Vorsatz
A = vektor.Punkt(1, 2, 3)

Liegt die Datei woanders, hilft der Suchpfad:

import sys
sys.path.insert(0, r"C:\Users\Anwender\OneDrive - ...\Website")
from vektor import *
Tipp hilfe() druckt eine Kurzanleitung ins Fenster, dir(A.weg) zeigt, welche Rechnungen einen Lösungsweg kennen, und jede Methode hat einen Docstring: help(Ebene.abstand).

3Die drei Konventionen#

Alles im Modul folgt denselben drei Regeln. Wer sie kennt, muss nichts nachschlagen.

1. Methoden liefern das Ergebnis – nie Text#

Jeder Aufruf gibt das mathematische Objekt zurück: eine Zahl, einen Vektor, einen Punkt, eine Gerade, ein Wahrheitswert. Damit kann sofort weitergerechnet werden.

g = Gerade(Punkt(1, 2, 3), Punkt(4, 0, -2))E = Ebene("E: 2x + 3y + 4z = 12")S = g.schneide(E)S.abstand(Punkt(0, 0, 0))√182/5

2. Derselbe Aufruf über .weg liefert den Lösungsweg#

x.weg.methode(...) rechnet genau dasselbe, gibt aber eine Rechnung zurück: print(...) zeigt den Weg als Text, .tex() als LaTeX, .ergebnis ist wieder das Ergebnis von oben.

a = Vektor(1, 2, 2, name='a')a.laenge()3r = a.weg.laenge()r.ergebnis3print(r)Länge-----|a| = |(1|2|2)|    = √(1² + 2² + 2²)    = √(1 + 4 + 4)    = 3
Hinweis Die alte Schreibweise rechnung=True bzw. latex=True funktioniert weiter: a.laenge(rechnung=True) liefert dieselbe Rechnung, a.laenge(latex=True) gleich den LaTeX-Quelltext.

3. Gerechnet wird exakt#

Koordinaten sind Brüche (Bruch, also fractions.Fraction), Längen sind Wurzelterme (Wurzel). Dezimalzahlen in der Eingabe werden als Dezimalbruch gelesen, nicht als Fließkommazahl.

Gerundet wird nur, wo gerundet werden muss: in ≈-Zeilen der Lösungswege, bei Winkeln (zwei Stellen) und wenn ausdrücklich gerundet(...) oder float(...) verlangt wird.

Zwei Zahlentypen genügen für die ganze Schulgeometrie.
